What it is

Every live tool, playable game and published article is a star, grouped into three constellations: tools, games, writing. Positions are laid out to read like a hand-placed constellation, not a grid, then joined star to star by a minimum spanning tree.

How it works on the real site

Each star links to its real page: /tools/slug, /games/slug or /learnings/slug. It only lists status live tools, enabled and interactive games, and published articles, the same rule the real site uses to decide what gets indexed. The four tools that need this site's own server (webhook inspector, link peek, dns sightline, chainsaw) render brighter and larger.

Cost & fallback

One canvas, device pixel ratio capped at two, animating only while this tab is visible and paused the instant the browser tab is hidden. Reduced motion drops the drift, twinkle and warp for a still sky; hover and keyboard selection still work. Without JavaScript nothing here would draw, so a shipped version needs a plain link list as its fallback.

What it is

The name is built from points sampled off real glyph pixels, about 2,200 to 3,500 of them on desktop and fewer on a phone, that gather into shape on load and answer to the pointer afterward.

How it works on the real site

Source Serif 4 is loaded and measured off screen before any sampling starts, with a timeout so a slow font fetch cannot hang the page. The pointer pushes and swirls nearby points on a damped spring; a click scatters them and the same spring pulls them back. The tools, games and writing links below go to the real hub pages.

Cost & fallback

Typed arrays and two batched fill paths per frame keep the draw cost flat from 900 points to 3,500. Reduced motion skips the assembly, the shimmer and the pointer well, and places every point at rest immediately. Without JavaScript nothing draws, so this concept falls back to the plain heading it already carries for screen readers.

What it is

A small shell that boots with whoami and ls, then hands over a real prompt. help, ls, cd, open, today, theme, clear, about and a sudo joke are all implemented commands, not decoration.

How it works on the real site

ls and open read the same live, enabled and published lists as the other two concepts, so every section and slug it lists is real. today computes the actual UTC time left before Quintle, Type Trial and Hue Hunt reset.

Cost & fallback

The typing animation is the only running timer, and it is cleared the moment the tab is hidden or reduced motion is on, when boot text appears all at once instead. Without JavaScript a shell has nothing to run, so a shipped version needs the same plain link list as the other two concepts.
